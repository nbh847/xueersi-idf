# required-extra-chars.txt — XMF1 字体包扩展字符表
#
# 用途：GB2312 全集（7445 码点）之外的、固件中文 UI 必须显示的字符，
#       必须在此逐行列出，否则 generate_font_pack.py / verify_font_pack.py
#       无法覆盖这些字符。字体生成工具会把本表并入排序后的 Unicode 索引。
#
# 格式：UTF-8，每行一个扩展字符；以 '#' 开头的行是注释，空行忽略。
#
# 约束（生成工具会强制校验，违反即非零退出）：
#   - 每个扩展字符必须能编码进 UTF-16 BMP（码点 <= 0xFFFF）。
#   - 扩展字符不得与 GB2312 全集重复。
#   - 最终码点表 = GB2312 ∪ 本表，升序且严格唯一。
#
# 当前节点 15B 的初始状态：尚无已确认的 GB2312 外缺字。
# 节点 15C 完成全系统中文 UI 迁移后，任何出现在中文文案中、且无法经
# gb2312 codec 编码的字符，必须补入本表；verify_font_pack.py 的
# --expect-chars 会扫描 UI 文案并对未覆盖字符非零退出。
