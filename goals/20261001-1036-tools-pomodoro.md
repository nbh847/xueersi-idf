## 目标与验收结果

在 Tools 中提供固定 25 分钟专注／5 分钟休息的番茄时钟。计时可开始、暂停、继续、重置（即按即生效）；离开 App 后继续，重新进入显示准确剩余时间。2026-10-01 实施当日流程调整为：**专注到点自动开始设定好的休息（不再手动选择），休息到点后显示「再来一轮」（A 开始新一轮，B 返回结束本轮）**；每轮专注由用户手动开始。

采用用户最终确认的正圆、中央圆润玻璃沙漏、沙漏左右两组小数字。动画可以简单，但必须优先保证稳定刷新和按键响应。专注及休息到点各短响 3 声，独立提醒开关放在番茄设置中并持久化，系统声音总开关优先。

交付包括固件源码、必要的配置与自测、人工验证命令及验收清单、实际验收证据、同步后的项目文档。只有必要人工验证通过后，功能才可标记完成。

## CP0 收口结论（2026-10-01，`/goal` 授权下采纳本文档建议方案）

- **设置入口按键映射**：详情页任意状态按 `↑` 进入「番茄设置」；`B` 在设置页原层返回详情页。进入或离开设置不暂停、不影响计时。方向键不用于跳段或重置；运行中 `↑` 同样有效。
- **蜂鸣器竞争与取消语义**：手动 Hardware Test 输出优先。提醒触发时刻若手动所有者正在输出，本次提醒静默消费，不排队、离开 Hardware Test 后不补响；提醒序列进行中时，Hardware Test 的手动 beep 抢占并取消剩余提醒（不补响）。取消接口只作用于提醒所有者的输出，不误停手动输出；提醒停止与取消均可重复调用。
- **触发口径**：到点提醒由 Pomodoro Service 的完成转换触发，只依赖「番茄到点声音」与系统 `sound_enabled` 两级开关；任一开关关闭时不补响，关闭动作取消尚未结束的提醒序列。

## 计时、页面与设置

- 使用独立 Pomodoro Service 持有状态与复制式快照：阶段、运行／暂停／完成状态、剩余时长、进度和单次完成事件。App 关闭不清空状态；重启回到未开始。
- 时间使用 64 位单调时钟 `esp_timer_get_time()`，以截止时间差计算，不逐秒递减；显示秒数向上取整，到零只转换一次。暂停保存剩余时长，继续重新设置截止点。
- Tools 菜单只有番茄时钟入口。详情 A 开始／暂停；B 返回 Tools，运行计时继续。暂停时左右选择继续／重置，A 执行，重置即按即生效（2026-10-01 用户取消二次确认）。专注到点响铃后自动进入休息；休息完成显示「再来一轮」，A 开始新一轮，B 返回结束。
- 番茄设置只含到点声音（默认开启）；读取完整 Settings 快照，只修改自己的偏好。写入失败保留原值，页面反馈保存失败；计时状态不写 NVS。
- 设置入口的按键映射尚未在预览中定义。施工前 CP0 收口：建议详情按 ↑ 进入番茄设置，B 原层返回，不暂停计时；不得擅自把方向键改为跳段或重置。
- Settings schema 升级需显式兼容 v1，保留原 Wi-Fi／声音值并为新偏好补默认值；不得擦除分区或重置 Wi-Fi 凭据。待机设计也规划了 schema 升级，后续应基于本任务最终 schema 增量演进，不重复覆盖版本。

## 声音与资源所有权

- 两级开关同时开启才发声：系统 `sound_enabled` 与番茄到点声音。系统关闭时，番茄设置显示对应说明。
- 每段完成只触发一次 3 声短响，988 Hz 为初值，每声约 150 ms，间隔约 150 ms。离开 Tools 时也检测完成并提醒；静音完成后不因打开开关或重新进页补响。
- 后台完成检测挂在已有 UI 主循环或全局轻量 timer，独立于 Tools 页面 timer；声音序列非阻塞，不用延时等待，不阻塞输入、Wi-Fi 或显示。
- 统一 Service 管理蜂鸣器驱动、停止时限及序列；Hardware Test 改为调用同一接口，禁止两套代码同时占用 GPIO14／LEDC。初始化失败只关闭声音能力，不阻塞启动或计时。
- CP0 必须先明确 Hardware Test 与提醒的竞争优先级及取消语义。建议手动硬件测试优先，提醒不打断测试、不无限排队、不在离开测试后补响；该取舍尚未由用户单独确认，不交给实现者猜测。
- 关闭任一声音开关时取消尚未结束的提醒并停止其输出；不能误停其他所有者的硬件测试输出。清理与停止必须可重复调用。

## 精简动画与性能边界

- 只保留单条落沙短线、6 档预生成沙堆、10 帧圆润玻璃翻转，去掉散沙。约 6 秒循环，最后约 0.5 秒翻转；这是状态装饰，不表示真实计时比例。
- 初始预算：落沙约 10 fps，沙堆约 1.1 秒变化，翻转约 20 fps。固定小帧或查表，不做逐帧昂贵旋转、动态申请、对象重建或全屏刷新。
- 缓存对象及帧数据，只更新变化的局部；倒计时和圆环约每秒更新。动画不得反过来推动计时或声音状态。
- 暂停冻结；完成、离开详情后停止动画更新并清理页面 timer／动画。后续待机覆盖时停止不可见动画，但计时／声音继续。
- 流畅度优先于特效数量。若翻转掉帧，先简化帧内容、减少帧数和拉长动作；仍不达标时提交简化预览及实测证据，不默默更换用户选定轮廓或宣称性能提升。
- 页面与输入性能必须实机验收。建议短期测量有效动画帧间隔和最长 UI 周期；预览帧率只是目标，不是通过证据。录像确认无肉眼卡顿，同时核对按键和联网服务无回归。
