## 目标与预期行为

- 普通固件启动进入 Launcher 后开始空闲计时，默认 2 分钟无按键进入待机；设置可选关闭、1、2、5、10 分钟，保存后重新计时，断电保留。关闭选项沿用本轮用户接受的功能概述，编码为 0 分钟；此前设计“不设永不”的候选已被替代。
- 待机全屏纯黑，隐藏原页面及 Wi-Fi 图标；中央显示用户已确认的小电视单圈简笔画，无外圈、填充、底部阴影、文字或状态栏。
- 任意六键唤醒，恢复原 App、页面和焦点。唤醒按键及释放前的输入全部吞掉，不误打开、暂停、返回或触发 Hardware Test 的 B 长按。
- App 对象与生命周期保持不变，番茄计时和到点提醒、Wi-Fi、Agent 等后台服务继续运行。
- 背光直连 VCC，本功能不关闭背光、不发送面板关闭命令、不进入低功耗休眠，不承诺省电。

## 已确认显示与动作

唯一视觉参考为 `docs/screen-idle-preview.html` 当前版本；早期截图、内嵌原 GIF 与双圈方案均不作为实现依据。预览迭代记录保留于 `goals/20261001-1359-screen-idle-preview.md`。

- 160 × 128 画布，中心 (80,64)，主体含天线动作约 104 × 90 px；左右约 28 px、上下至少 18 px 安全边距。
- 浅白 `0xE8E8E6` 线条；单圈圆润轮廓、斜眼、小嘴、顶部两侧外张短天线。保持宽高比，机身不平移、不晃动。
- 眨眼：4.6 秒周期，在 42%～46% 阶段短暂闭眼；从斜眼变为圆头水平线，保持线宽。
- 天线：左右分别以根部旋转，4.8 秒周期，60%～82% 阶段轻抬、回落；左右镜像抬起 13 度，短暂回落 5 度，类似动物耳朵动作。根部不能脱离轮廓。
- 嘴巴：5.8 秒周期，60%～84% 阶段轻微加深原有双弧曲线，不换表情、不移动机身。
- 按 HTML 的 `translate(80 64) scale(1.6) translate(-82.5 -69)` 换算到屏幕坐标。轮廓线宽约 3.5 px，眼睛与天线约 7.2 px，小嘴约 2.4 px；LVGL 按可用整数像素取整，目标板复核后仅可微调线宽和采样，不改变已确认造型。

## 实现决策

### 配置与迁移

实施前基线为 schema v3、五项业务字段。现已新增 `uint8_t screen_idle_minutes`，合法值仅为 0／1／2／5／10，默认 2；NVS 固定宽度 blob 升至 v4，继续使用 `xiaomiao/settings`。

迁移支持 v1、v2、v3：保留该版本已有全部字段，缺少的番茄字段沿用现有默认补全，仅给待机字段补 2。未知版本、非法值、错误长度走现有单 key 恢复策略；不擦除分区，不丢 Wi-Fi 凭据。迁移提交失败保留合并后的内存配置并标记降级；用户保存失败保留旧内存和持久化值，Display 页回退并提示错误。

### 输入与页面生命周期

在现有去抖输入边界以六键按下／释放更新活动时间，不建立第二条 GPIO 输入链；按住任意键时不得进入待机，释放后重新计时。后台刷新不延长超时，使用 64 位单调时间比较。

状态至少区分正常、待机、唤醒吞键至全部释放。输入过滤必须早于 Hardware Test B 手势和 LVGL 按键转发；包含同时按下、多键交叠与长按重复，不因单个唤醒键释放就放行其他仍按住的键。唤醒不播放焦点光带。

覆盖层挂在 LVGL top layer 并置顶，遮住 Wi-Fi 图标，不获取 group 焦点；进入／退出不调用 App open／close、不切 screen、不改变焦点。所有 LVGL 操作在既有 UI 任务执行，不新增 FreeRTOS Task、锁或后台队列。

### 绘制与资源

使用 LVGL 基础线条、采样曲线／折线绘制。用一个仅在待机时活跃的 LVGL timer 或等价动画推进眼睛、天线、嘴巴，最高约 20 fps，仅动作时请求局部重绘，不新增全屏画布或 DMA 缓冲。按绝对时间计算相位，避免累计漏帧。

退出待机先停 timer／动画再释放对象及点数组，进入失败清理部分对象并保留原界面正常输入；不得出现黑色空层锁住设备。重复待机不累积对象。自测启动分支不接入普通 UI 待机链。

Display 菜单的「息屏设置」子页提供关闭／1／2／5／10 分钟候选，↑↓ 切换、A 保存、B 不保存返回，失败时以消息行报错；焦点切换接入纵向 8 px 光带、140 ms ease_out、浅白 `0xE8F0FF`，遵循项目交互规范。中英文字段不得溢出 160 × 128。

### 人工验证命令与场景

人工先加载 ESP-IDF 6.1 环境，在仓库根目录运行：

```bash
idf.py -p COM5 flash monitor
```

端口按实际设备替换；flash 会按需构建。Agent 不运行构建、烧录、串口或硬件命令。Settings 自测按现有独立构建选项人工执行，普通固件复验须恢复默认关闭自测。

1. 无 SD 启动到 Launcher，无新增错误；默认约 2 分钟进入待机，主体及动作均完整可见，Wi-Fi 图标被遮住。
2. 六键逐一唤醒，每个键只唤醒，松开后的下一次按键才执行页面动作；同时按键和交叠释放同样安全。
3. Hardware Test 待机后按住 B 超过 800 ms，不能退出、翻页或操作外设；释放再按符合原有语义。
4. Launcher 和五 App 的菜单、详情、焦点保持；Hardware Test 15 页回归，特别检查 B 长短按和原有外设操作。
5. 选关闭后不进入待机；1／2／5／10 分钟生效，成功保存重新计时，重启保留；B 取消不改设置，保存失败不改已生效值。
6. 已按住键到达超时阈值不待机，释放后重新计时；后台监控刷新不阻止进入。
7. 番茄运行中进入待机，计时继续；专注到点自动休息、各阶段提醒只响一次，唤醒不暂停或补响；两级声音开关继续有效。
8. 待机期间 Wi-Fi 断线重连与 Agent 更新继续；唤醒后读取最新数据，图标恢复原页面应有可见性，番茄页不得误显示图标。
9. 至少 20 次待机／唤醒，检查对象数、内部 heap 和最大连续块，无单调泄漏、无未释放 timer／动画、无闪退；配网会话中待机／唤醒不打断网络。
10. 自测固件迁移保留 Wi-Fi、系统声音、番茄声音与时长；损坏值恢复、合法值重启、迁移失败语义分别留证。难以实机注入的失败路径标记静态／宿主验证，不冒充实机通过。
