# 空闲待机画面与按键唤醒设计

状态：已实现并取得负责人构建、烧录及实机测试全部通过确认。2026-10-01 16:22；口头确认，未附新日志或照片，独立自测固件记录未提供。施工与验证证据见 `goals/20261001-1449-screen-idle.md`。

## 功能与显示

默认 2 分钟无按键操作进入全屏黑底待机，在 Settings → Display 选择关闭、1、2、5、10 分钟，保存后生效并持久化。按住任意键不进入待机，后台刷新不算用户操作。

屏幕仅显示用户确认的单圈小电视简笔画：浅白线条、黑底、无外圈、机身填充或阴影，无文字和 Wi-Fi 图标。机身固定，眨眼、左右外张天线像耳朵轻抬回落、小嘴轻微开合。按 160 × 128 屏幕适配，主体含动作约 104 × 90 px，中心 (80,64)，四周保留安全边距。

视觉依据：[HTML 预览](screen-idle-preview.html)。尺寸、动作周期、关键帧及代码范围统一见 [施工清单](../goals/20261001-1449-screen-idle.md)；此前候选和浏览器截图证据保留于 [预览迭代记录](../goals/20261001-1359-screen-idle-preview.md)，不以旧候选作为实现依据。

## 唤醒与硬件边界

任意六键唤醒，首次按键及所有键释放前的输入只负责唤醒，不能触发页面操作或 Hardware Test B 长短按。恢复原 App、页面、焦点和状态；覆盖层不触发 App open／close，不改变 group 焦点。Wi-Fi、Agent、番茄计时和到点声音继续运行。

背光直连 VCC，无法软件关闭或调节。本功能不关闭面板或后台服务，不进入低功耗模式，不承诺省电。

## 实现基线与验证

待机控制放在 framework/UI 输入边界，使用既有 LVGL 任务；覆盖层位于 top layer 最前方。采用 LVGL 基础图形重绘，不直接嵌入参考 GIF，不依赖 SD 或新组件。退出前停止 timer／动画再释放对象，失败不得影响原页面输入。

当前 Settings Service 为 schema v4，新增待机分钟字段；保留 v1／v2／v3 已有字段，待机默认 2，关闭编码为 0。用户保存成功才更新运行态，迁移失败沿用现有降级策略；不擦除 NVS 分区或 Wi-Fi 凭据。Display 选择行遵循项目光带特效约定。以上配置、状态机、覆盖层与 Display 页代码均已实施，构建、烧录与实机验收由人工执行。
