# 空闲待机画面与按键唤醒开发设计

状态：方案待审，未实现，未构建或实机验证。2026-09-27 19:20。

## 实施顺序与依赖

本设计是已确认实施顺序的第 3 步，在 Launcher 与 Tools／Settings 信息归位、Tools 番茄时钟分别实施并验收后接入；当前进度以 `ROADMAP.md` 为准。待机涉及全局按键与覆盖层，最后实施以便集中验证全 App 回归，以及待机期间番茄计时继续、六键唤醒并吞掉唤醒键、原页面与焦点恢复、长按 B 不误触发。番茄时钟本身不依赖本功能。顺序确认不代表本设计细节已全部审定。

## 目标与硬件边界

- 普通固件启动后，默认连续 2 分钟没有按键操作，进入全屏黑底待机画面；画面中央显示静态的 B 站小电视占位图。以后可替换为动画，本次不实现动画。
- 在 `Settings → Display` 修改自动进入时间。按任意一枚实体键唤醒后，恢复进入待机前的 Launcher 或 App 页面、焦点与页面内部状态。
- `README.md` 与 `docs/project-overview.md` 已确认屏幕背光直连 VCC，无法软件关闭或调亮度。因此本功能是“黑底待机画面”，不是真正关闭背光／面板或低功耗休眠；黑色区域仍可能发光，也不承诺省电。现有 `ST7735_DISPOFF` 命令不能与“面板黑屏上仍显示小电视”同时成立，本次不发送该命令，不停止 LVGL、Wi-Fi、Agent 或其他后台服务。

| 责任 | 当前事实 | 设计落点 |
| --- | --- | --- |

## 用户行为

1. 可选时间暂定 `1 分钟`、`2 分钟`、`5 分钟`、`10 分钟`，默认 `2 分钟`。这是本设计对“可以在设置里设置”的具体化；不设“永不”，避免额外的关闭功能。设置页显示当前值，上下键切换候选项，A 保存，B 返回。保存失败时保持原值并显示错误，成功后立即按新时长重新计时。
2. 空闲的定义是六枚实体键都未产生新的**去抖按下边沿**。长按期间不得熄屏；释放后重新计时。后台数据刷新、LVGL 定时器、网络通信和屏幕刷新不算用户操作。启动进入 Launcher 后开始计时。
3. 到达超时时显示纯黑背景和居中的静态小电视。它覆盖包括顶层 Wi-Fi 图标在内的原画面。原页面对象、焦点、菜单索引和 App 生命周期保持不变；后台服务继续运行。小电视用少量 LVGL 基础图形绘制在覆盖层中，不引入图片下载、SD 依赖或新的运行时组件。视觉尺寸、配色在 160 × 128 实机上复核。
4. 待机时任意键的首次去抖按下只负责唤醒，不传给 Launcher／App，也不能触发 Hardware Test 的 B 长短按动作。该键的重复事件及释放前持续按住的输入全部吞掉；释放后才恢复正常键处理，并从唤醒时重新计时。唤醒后仍显示进入待机前的页面与焦点。若是 PC Monitor 等动态页面，其数据可继续刷新，所以“之前的页面”指页面和交互状态，并非冻结的旧数值。
5. 待机期间不允许覆盖层获得输入焦点。重新进入待机时重新创建或显示同一覆盖层，不累积 LVGL 对象。

## 实现方案

1. 在 UI 输入／显示边界增加一个小型待机控制模块，供 `keypad_read_cb()` 和 `lvgl_task()` 调用。输入回调只记录去抖边沿、返回“吞键还是透传”的结果；创建／移除 LVGL 覆盖层在 LVGL 任务中完成。先处理唤醒状态，再调用 Hardware Test 的 B 手势更新，保证唤醒 B 不进入其手势状态机。按键已按住时不进入待机。
2. 覆盖层属于固件级 UI，而非一个业务 App。保留 active screen 与当前 group 焦点；覆盖整个 160 × 128 可见区域，优先核对它与 top layer Wi-Fi 图标的层叠关系。进入时遮住全部旧画面，退出时使原页面完整重绘。动画接口暂不预留；未来动画只替换覆盖层内容和过渡，不改变计时、输入与配置语义。
3. `xiaomiao_settings_t` 增加一个以分钟为单位的待机时间字段。NVS blob 升至 v2，固定宽度编码并校验合法值；读取 v1 时保留原两项设置，仅给新字段补默认 2 分钟，再尝试将该 key 升级写入 v2。升级写失败时继续使用合并后的内存配置，标记未持久化并保留错误；不能把已有 Wi-Fi／声音偏好重置成默认值，也不能擦除 NVS 分区。v2 损坏仍沿用 Settings Service 现有的单 key 默认恢复策略。对应自测扩展 v1 升级、v2 值域、断电恢复和写失败语义。
4. `Settings → Display` 使用现有 App 的页面和按键模式，替换只读文案为超时值选择与固定背光说明。保存时读取完整配置快照，只修改待机字段，经 `xiaomiao_settings_set()` 提交后再更新页面。超时控制模块读取已提交的快照；失败时保持原超时值。中文和英文都需在 160 × 128 屏幕内完整显示。

## 范围与检查点

| 检查点 | 交付 | 验收方式 |
| --- | --- | --- |
| CP1 配置 | v2 字段、默认值、v1 保值升级、合法值校验、Settings 选择页 | 静态核对编码／解码和 Settings 调用边界；人工运行 Settings Service 自测与断电重启 |
| CP2 待机与唤醒 | 全局空闲计时、黑底小电视覆盖层、按键吞键及页面恢复 | 静态检查输入状态顺序和对象释放；人工逐页验证六键唤醒、长按 B、焦点／页面保留 |
| CP3 回归 | 启动、五 App、配网状态页、Hardware Test 15 页不因待机丢失状态 | 人工 `idf.py build` 或 `idf.py -p COM5 flash monitor`，并在目标板观察显示、按键和串口无新增错误；Agent 只复核源码、diff 与人工证据 |

重点边界：到达阈值时已有键按住；阈值前后按键去抖；刚唤醒时 B 继续按住超过 800 ms；设置保存失败；v1 配置升级后原 Wi-Fi 自动连接值与声音值不变；多次待机／唤醒不泄漏对象；后台刷新不能阻止待机。

## 待审决定

- 请确认“熄屏”按本方案理解为**背光常亮的黑底待机画面**。如果目标是物理黑屏或显著降功耗，当前原厂硬件与“黑屏上显示静态小电视”条件相冲突，需要另定硬件或展示方案。
- 时间选项暂定 `1／2／5／10 分钟`。若需要 `30 秒` 或“永不”，在实施前调整候选值和对应验收案例。
