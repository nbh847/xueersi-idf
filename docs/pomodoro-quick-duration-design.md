# 番茄时钟专注时长快速切换设计

状态：负责人已确认设计（2026-10-02 17:53），已实施并通过负责人实机验收（2026-10-02 18:39，口头确认）。施工入口：`goals/20261002-1753-pomodoro-quick-duration.md`。

## 目标

进入番茄时钟的专注准备页后，通过左右键快速选择 **1、5、15、25、30、45、60 分钟**。初始默认仍为 25 分钟；已有保存值优先，不因进入页面恢复默认。

快速选择直接更新现有专注时长配置。随后按 `↑` 进入番茄设置，「专注时长」显示刚才选择的值；「休息时长」保持原值。设置页修改专注时长后，返回未开始页也显示修改后的值。

## 按键与状态

建议快切只在未开始状态启用，确保方向键不会改变正在进行的一轮计时。

| 页面状态 | 左右键 | 其他操作 |
| --- | --- | --- |
| 未开始的专注页 | 左键选上一档，右键选下一档 | A 按当前时长开始；↑ 进设置；B 返回 |
| 专注或休息运行中 | 保持现有行为，不快切 | A 暂停；↑ 进设置；B 返回且计时继续 |
| 专注或休息暂停 | 保留「继续／重置」的选项切换 | A 执行选项；重置后回到未开始页，可快切 |
| 休息结束 | 保持现有选项行为，不快切 | A 按当前配置开始下一轮；也可进设置修改时长 |
| 番茄设置页 | 保留逐分钟编辑 | 专注 1～180 分钟，休息 1～60 分钟 |

固定档位按升序循环：`1 → 5 → 15 → 25 → 30 → 45 → 60 → 1`，左键反向。例如 25 分钟左切为 15、右切为 30；1 分钟左切为 60、60 分钟右切为 1。

设置页仍允许自定义非档位值。当前为 20 分钟时，左键选择严格小于当前值的最近档位 15，右键选择严格大于当前值的最近档位 25；当前为 90 分钟时，左键选择 60，右键循环到 1。进入页面本身不把自定义值吸附到档位。

每次实体按下左右键只切一档；按住不连续切换，避免循环过快及重复写入。该释放锁存仅用于详情页快切，不改变设置页现有编辑行为。

## 画面

保留现有 86 px 正圆、中央沙漏和左右分钟／秒数。未开始时在圆环外侧左右各增加一个小箭头，提示可切换；开始计时后隐藏。

```text
             专注

       ←  （正圆计时区）  →
             25  00
          中央玻璃沙漏

       A 开始   ↑ 设置   B 返回
```

草图仅表达区域关系，数字与沙漏仍采用当前固件的环内布局。箭头建议使用线段绘制，避免依赖新增字形；不将七个档位同时铺在小屏上，也不新增操作栏。

选值成功后立即更新分钟、秒数 `00` 和完整圆环。分钟显示区域作为当前选择区域，附带横向光带扫入：12 px 竖带、140 ms `ease_out`、浅白 `0xE8F0FF`，由按键对应侧扫入。复用项目动效规范，静态值先更新，快速连按取消前段，离页先删除动画再删除对象；分配失败只跳过动效。光带限定在分钟区域，避免遮挡沙漏和秒数。

保存失败时保留原值，不播放成功动效；临时用底部提示区显示现有「保存失败」文案，之后恢复按键提示。实际箭头位置、光带范围及中文／英文提示宽度在实现时核对，最终以实机为准。

## 配置同步与保存

采用现有 Settings Service 的 `focus_minutes` 作为唯一已保存值，不另设一份快捷时长偏好。

每次有效快切按以下顺序执行：

1. 读取完整设置快照，根据 `focus_minutes` 计算目标档位。
2. 只修改 `focus_minutes`，原样保留 `break_minutes`、声音、Wi-Fi、待机等其他字段。
3. 调用 `xiaomiao_settings_set()` 保存；成功后刷新计时快照及画面。
4. 失败时保持原配置和倒计时展示，并给出失败提示。读取失败时同样不切换。

建议每次有效按下即保存，逻辑直接且无需离页补存；因此离开 App、重新进入或重启后保留最后一次成功选择。默认值仍是 25 分钟。仅值发生变化时写入，不在刷新定时器中保存，不因页面打开而写入；按住不重复切换。此次不增加延迟合并写入机制。

现有 Settings Service 在写入提交成功后才发布内存快照，失败保持原值；设置页打开时已从 Service 读取专注和休息时长。Pomodoro Service 的未开始快照也直接读取专注配置，因此无需新增时长字段、NVS schema 版本或计时接口。

运行／暂停期间在设置页修改时长，继续遵循现有阶段规则：当前阶段的总时长和剩余时间保持不变，专注配置用于下次开始，休息配置用于下次进入休息。专注到点自动休息、声音提醒、跨 App 与待机计时均保持原语义。
