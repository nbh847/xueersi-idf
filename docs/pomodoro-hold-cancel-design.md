# 番茄时钟长按 A 引信取消设计

状态：负责人已确认设计（2026-10-02），视觉采用四款交互式 HTML 预览 `docs/pomodoro-hold-cancel-preview.html` 中的「银白星芒」，专注与休息运行态共用此效果。2026-10-02 18:59 负责人整体确认验收通过，固件实施与收口已完成；证据为人工确认，未附日志或照片，故障注入证据边界见施工文档。

## 目标与范围

施工入口：`goals/20261002-1841-pomodoro-hold-cancel.md`。施工 CP0～CP5 已完成。

在专注或休息运行页（底部显示 A 暂停、B 返回）持续长按 A，用沿倒计时圆环燃烧一周的引信动画确认取消。动画完整持续 2 秒；中途松开则撤销取消意图，计时继续。完成后直接进入番茄时钟未开始的专注准备页，不返回 Tools 菜单、不弹确认框。

取消只重置本轮运行状态，不修改任何已保存配置。准备页显示当前保存的专注时长与完整圆环，专注／休息时长、声音及其他设置保持原值，包括此前通过快速切换保存的专注时长。取消不代表完成当前阶段，不进入下一阶段，不发到点提醒。休息取消后同样回到专注准备页，不回到休息初始时长。

专注与休息运行态均启用同一取消手势。暂停页的「继续／重置」、未开始页与设置页保持现有操作；不新增配置项、NVS schema 或全局按键规则。

## 按键时序

已确认长按识别门槛沿用当前 keypad 的 **360 ms**，门槛之后才开始 **2000 ms** 燃烧。因此从实体按下到完成取消约为 **2.36 秒**，另有现有输入去抖和刷新延迟。360 ms 是已确认的识别门槛，2 秒是用户要求的动画时长，两者分别计时。

| 阶段 | 行为 |
| --- | --- |
| A 按下，尚未达到 360 ms | 记录本次按下，不立即暂停；画面与计时继续 |
| 360 ms 前松开 | 认定为短按，执行一次原有暂停操作 |
| 持续按住达到 360 ms | 从圆环顶部点燃，开始新的 2 秒确认动画；本次按键已消费，不能再触发暂停 |
| 动画未满 2 秒时松开 | 立即撤销动画，恢复当前真实计时圆环；不暂停、不重置、不补回经过的时间 |
| 动画满 2 秒且 A 仍按住 | 执行一次本轮重置，直接显示专注准备页 |
| 完成后继续按住或松开 A | 吞掉本次按键的重复与释放，直到全部释放；不会立即开始新一轮 |
| 撤销后再次长按 | 重新识别长按，火花仍从顶部起步，重新完整计时 2 秒，不累计上次进度 |

短按暂停延后到松开时执行，是区分短按与长按所需的交互变化。不能先暂停再进入燃烧，否则松手时已经改变了本轮状态，违背「无事发生」。

进入专注或休息运行页时如果 A 尚未释放（例如用 A 开始计时或从菜单进入），必须先等待释放再允许识别取消。开始一轮的同一次长按不能顺便取消这一轮。

## 引信动画

沿用现有黑底、直径 86 px、宽度 5 px、中心约为 `(80, 64)` 的正圆，不改变圆环尺寸与数字／沙漏位置。

- 起点：固定为圆环最上方的 12 点钟方向，不采用当前剩余进度的端点。
- 方向与速度：从顶部顺时针，线性匀速走满 360°，2000 ms 完整回到顶部。不用缓入缓出，避免引信忽快忽慢。
- 火花：采用仙女棒式不规则溅射，采用已选定的「银白星芒」：近白亮核约 1.7 px，周围约 8 根银白／冷白细火丝长短交错闪烁，单侧长度约 2.5～8.5 px，少量火星带微小十字星尖，并有少量脱离燃点的火星飞出后熄灭。2026-10-02 负责人明确要求放大周边溅射，而不是圆形光点；预览已缩小实心亮核、减弱柔光并扩大火丝范围。火花是局部颜色强调，圆环其他区域仍使用原有黑／灰／白配色。
- 燃烧过的部分：火花经过即直接变为现有圆环背景灰 `0x383838`，不渐变、不留白色拖尾。已自然耗尽的灰色弧段继续保持灰色，火花也照常沿完整圆周经过它，不跳段、不缩短时间。
- 尚未烧过的部分：按正常倒计时进度显示，原本为白色的剩余弧段仍为 `0xF2F2F2`。燃烧覆盖与计时显示独立，不能把剩余进度强行变回完整白圈。
- 中央数字与沙漏：计时继续，数字按当前真实剩余时间更新，沙漏维持运行表现；不增加第二套倒计时数字。
- 提示：燃烧时底部临时显示「松开继续」；普通提示在撤销后恢复。英文回退建议 `Release to keep`，实施时核对宽度与字库覆盖。

| 燃烧经过时间 | 火花位置 | 已覆盖成灰的范围 |
| --- | --- | --- |
| 0 ms | 顶部 | 起点 |
| 500 ms | 右侧 | 顶部顺时针至右侧，约 1/4 圈 |
| 1000 ms | 底部 | 约 1/2 圈 |
| 1500 ms | 左侧 | 约 3/4 圈 |
| 2000 ms | 回到顶部 | 完整一圈，随后进入准备页 |

松开后不播放倒放或额外恢复动画，直接移除灰色覆盖与火花，按最新快照恢复圆环。取消成功时不额外停留全灰画面，准备页重新显示完整白圈和已保存的专注时长。

## 计时边界与离页

燃烧属于 App 内的确认状态，不暂停 Pomodoro Service，也不提前调用 reset。长按识别与燃烧全程使用当前阶段真实快照：不冻结时间、不重设截止时间、不修改总时长或剩余时间，也不切换到固定示例进度。底层倒计时弧持续更新，灰色燃烧弧仅是独立视觉覆盖；松开后展示包含这段实际消耗时间的最新进度。

HTML 的「四款同步演示」为便于比较会重置到固定示例 `18:24`，此行为仅用于预览，不进入固件。正式交互从用户长按时的当前进度开始叠加效果。

- 燃烧期间专注自然到点：先采用 Service 的正常到点结果，撤销本次取消手势并进入休息，提醒沿用原规则。本次 A 消费到释放，不能继续取消休息。确认期间不能冻结倒计时来争取额外时间。
- 同一轮检查同时观察到释放与动画截止：释放优先，只有确认 A 仍按住才允许重置。以去抖后的输入状态为准，不能只靠动画完成回调取消。
- 燃烧期间休息自然到点：撤销手势，采用 Service 的正常休息结束状态与原提醒规则；本次 A 消费到释放，不把已结束阶段重置成准备页。
- 同一轮检查同时观察到阶段到点与动画截止：先刷新 Service 状态，只有仍为发起手势时的原阶段运行态才可取消；专注已转休息或休息已结束时，不执行重置。阶段转换后须先释放 A，再重新长按，才能取消新的运行阶段。
- B 返回或 ↑ 进入设置：先撤销手势并清理动画，再执行原有导航，计时继续。返回计时页不得恢复上次燃烧进度；若 A 尚未释放，先等待释放。
- 失去 A 按住状态、输入被唤醒流程吞掉、页面销毁或 App 关闭：撤销本次确认，不允许后台完成取消。其他方向键在确认期间不改变计时和配置。

## 实现建议与文件边界

当前 `main/apps/tools/xiaomiao_tools.c` 的 `LV_EVENT_KEY`／`LV_KEY_ENTER` 分支直接执行 `detail_action()`；现有 App 定时器已读取 keypad 的状态与按键，并处理释放锁存。因此建议在 Tools 内增加局部 A 手势状态机，复用去抖后的 keypad 状态和现有定时器，避免改全局长按阈值或按键驱动。

手势可分为「等待释放、空闲、短按待定、燃烧确认、消费至释放」。按下时记录单调时间；每次更新先检查页面、A 是否仍按住与 Service 状态，再按绝对经过时间计算燃烧角度。不能把 LVGL 的重复 KEY 事件当作新的按下，也不能依靠帧数累计 2 秒。

绘制建议保留原倒计时 arc，额外叠加同心、同宽的灰色覆盖弧与少量火花图元；所有图元不加入输入 group、不影响焦点。普通每秒刷新不能覆盖正在燃烧的视觉层；复用 App 刷新定时器推进火花，实机核对流畅度，不新增任务或第三方依赖。

圆环覆盖、火花定位与完成条件使用同一归一化进度 `clamp(elapsed / 2000 ms, 0, 1)`；圆环顶部旋转与顺时针方向在实施时核对，验收以四个方向的截图为准。粒子使用固定相位，无需随机数或大量对象。

动画对象创建失败时不允许无反馈地完成取消：撤销手势、保持当前阶段运行，并消费本次 A 至释放。页面离开或销毁前先停止更新／删除动画，再删除对象与清空指针，防止回调访问已释放对象。

| 文件 | 计划职责 |
| --- | --- |
| `main/apps/tools/xiaomiao_tools.c` | 专注／休息运行态短／长按分流、确认进度、圆环覆盖与火花、释放锁存、离页清理 |
| `main/framework/xiaomiao_i18n.c`／`.h` | 必要时新增「松开继续」及英文回退 |
| `main/services/xiaomiao_pomodoro_service.c`／`.h` | 原则上不修改；复用现有快照与 `xiaomiao_pomodoro_service_reset()` |
| 设计与进度记录 | 后续授权实施时同步实际决策和验证证据 |

现有 reset 只清除计时状态与待消费完成事件，准备页快照重新读取保存的专注时长；不调用 Settings 写接口。实施时重点检查取消路径不存在 `xiaomiao_settings_set()` 或其他持久化写入。
