# Tools 番茄时钟开发设计

状态：方案待审；仅文档，未修改固件，未构建或实机验证。2026-09-27 19:33。

## 实施顺序与依赖

本设计是已确认实施顺序的第 2 步，在 Launcher 与 Tools／Settings 信息归位独立验收后实施，空闲待机画面随后实施；当前进度以 `ROADMAP.md` 为准。计时根据实际经过时间计算，不依赖页面刷新次数，也不依赖待机功能先实现。本步独立验收开始、暂停、继续、完成及离开 App 后计时准确；待机期间继续计时的集成验收留到第 3 步。顺序确认不代表本设计细节已全部审定。

## 产品目标与边界

在 `Tools` 中提供第一个真正可用的工具：番茄时钟。第一版采用标准的 **25 分钟专注 + 5 分钟短休息**。用户手动开始每一段；完成专注后可以选择再来一轮或进入休息，不自动跳段。计时不中断其他 App 的使用：离开 Tools、进入黑底待机画面后仍按真实经过时间前进，返回时显示准确状态。

第一版不做时长自定义、长休息、轮次统计、任务清单、提醒音、震动、联网同步或跨重启恢复。当前 `sound_enabled` 偏好尚无实际 Audio Service 消费者，因此结束时只提供屏幕内完成状态，不虚构声音提醒。计时完成时若用户在其他 App 或待机画面，本版不弹全局提示；重新打开番茄时钟即可看到完成状态。这个限制需要在验收说明中明确。

## 与已写设计的关系

[Launcher 与 Tools／Settings 信息归位设计](launcher-tools-settings-reorganization-design.md) 仍负责把 Tools 现有 Wi-Fi、System Info、About、Assets 迁入 Settings，并把 Games 放到 Launcher 第三格。该设计此前把 Tools 写成“暂无工具”空状态；**本设计更新其目标状态为仅有「番茄时钟」一个入口**。若两个方案分步实施，信息归位后至番茄时钟落地前可以短暂显示空状态；最终验收以本设计的单入口 Tools 为准。历史上的四项诊断信息不回流 Tools。

[空闲待机画面设计](screen-idle-design.md) 到时会覆盖当前 App 画面，但不暂停番茄计时。任意键唤醒只恢复原页面且吞掉唤醒键；返回番茄界面时按当前时间更新圆环和数字。

## 视觉方案

我建议采用你提出的**黑白圆环倒计时**，这比在 160 × 128 小屏上铺满卡片或数字更清楚。区别是：圆环本身也表示剩余比例，数字负责精确时间，二者互相补足；页面不放番茄插画、渐变或大面积装饰。

| 区域 | 位置与样式 | 用途 |
| --- | --- | --- |
| 底色 | 全屏纯黑 `#000000` | 让圆环、时间与状态形成主次；背光直连 VCC，黑底不代表物理关屏 |
| 顶部 | `y=2～17`，12 px 小字，白色／浅灰 | 显示 `专注` 或 `休息`；暂停或完成时用文字明确状态 |
| 圆环 | 中心约 `(80,62)`、直径约 `82 px`、线宽 `5～6 px`；暗灰底环 `#383838`，剩余弧为近白 `#F2F2F2` | 初始完整一圈，从 12 点方向顺时针缩短；到 0 时仅留底环，不用颜色作为唯一状态信号 |
| 时间 | 圆心居中，`MM:SS`，近白；目标使用约 24 px 等宽数字，固定宽度与位置 | 运行与暂停均显示剩余时间；秒数变化只重绘时间和圆环 |
| 底部 | `y=107～125`，12 px 小字或两个紧凑操作项 | 按状态显示最少的可执行操作；B 返回始终可用 |

目标屏幕草图，比例与字距以实机为准：

```text
┌──────────────────────┐
│        专注          │
│     ◜────────◝       │
│    │          │      │
│    │  24:59   │      │
│    │          │      │
│     ◟────────◞       │
│   A 暂停     B 返回  │
└──────────────────────┘
```

运行时屏幕保持纯黑和灰白层次。全局 Wi-Fi 图标目前位于 LVGL top layer 且使用彩色；若要严格保持黑白，番茄详情页打开期间应由 Framework 提供受控的可见性接口暂时隐藏它，离开详情页或关闭 Tools 时恢复。不能由 Tools 直接销毁图标或更改 Wi-Fi Service。Tools 菜单仍沿用项目现有配色，进入计时详情页才切换为黑白，以让番茄画面完整、安静。

现有默认配置只启用了 LVGL Montserrat 12／14，项目中文字体为 12／16 px；24 px 数字并非现成可用。实施前先核对 LVGL 9.5 自带的 24 px Montserrat 字体编译选项与固件体积，仅让计时数字使用它；不把字体选择冒充为已实现事实。若启用后尺寸或 Flash 预算不合适，再以目标板样张比较 16 px 数字与小型数字字模，不能默默把主时间缩到难读。

## 页面与按键

`Tools` 菜单仅有一项 `番茄时钟`。A 进入，B 返回 Launcher。番茄详情页根据状态显示：

| 状态 | 画面 | 按键 |
| --- | --- | --- |
| 未开始 | 完整白环，中央 `25:00`，标题 `专注` | A 开始 25 分钟；B 回 Tools 菜单 |
| 运行中 | 白弧随剩余时间缩短，中央 `MM:SS`；秒级更新 | A 暂停；B 回 Tools 菜单，计时继续 |
| 已暂停 | 停住的圆环和剩余时间，标题 `已暂停`，底部有 `继续／重置` 两项 | 左／右选项，A 执行；B 回 Tools 菜单且保持暂停。选择“重置”后先显示确认，A 确认回到本段初始时长，B 取消 |
| 专注完成 | 中央改为 `完成`，圆环收敛为静态完成样式，底部 `再来一轮／休息 5 分钟` | 左／右选择，A 启动相应一段；B 回 Tools 菜单 |
| 休息运行／暂停 | 同一圆环布局，标题为 `休息`／`已暂停`，初始 `05:00` | 与专注运行／暂停相同 |
| 休息完成 | 中央 `休息结束`，底部显示 `开始专注` | A 开始新一段 25 分钟；B 回 Tools 菜单 |

暂停与完成状态的两个操作项需在 160 × 128 实机上保持清楚的焦点样式，不能缩小到难读；必要时让底部两项分两行或改为独立轻量选择页，圆环仍是主画面。方向键仅在有选项的状态改变焦点，不在运行中切换阶段。A／B 的重复按键按现有释放锁存规则处理，一次实体按下只执行一次动作。不会因为误按方向键跳过工作或重置计时。

## 计时语义与实现落点

- 计时状态独立于 Tools 的 LVGL 页面对象，使用设备启动后的 64 位单调时间 `esp_timer_get_time()` 计算截止时间；不靠每秒回调递减整数，避免 App 关闭或屏幕待机期间漏秒。运行态读取快照时以 `max(0, deadline - now)` 得出剩余时间；显示秒数采用向上取整，使开始时确实显示 `25:00`，不会立刻跳 `24:59`。到达 0 后只转换一次完成状态，不出现负值。
- 暂停时保存剩余时长；恢复时从当前单调时间设新截止点。B 离开详情页只销毁 UI 对象和 UI 刷新 timer，不销毁计时状态。重新进入时读取最新快照并重建圆环。设备重启后回到未开始；本次不写 NVS，避免每秒写 Flash。
- Tools App 只处理菜单和详情呈现；计时状态可放在独立的小型 `main/services/` 模块，或先放在不会随 App `close` 清空的私有状态中。选型以实现时最小可测范围为准；若需要后台完成状态查询，优先独立模块。无论落点如何，都不新增 FreeRTOS 任务或依赖网络时间。
- LVGL 页面约每秒更新数字与弧线；保留现有单块 DMA 缓冲，不使用全屏逐帧动画或新的位图资源。圆环优先核对项目已锁定的 LVGL 9.5 `arc`／绘图能力，避免自己维护一套像素缓冲。所有 LVGL 调用留在 UI 任务中。
- 进入页面时创建、离开时释放对象和刷新 timer。Wi-Fi 图标隐藏／恢复与页面生命周期成对，即使中途 A／B 切换或构建对象失败也不能留下全局图标被隐藏的状态。

## 验收检查点

| 检查点 | 静态检查 | 人工验证 |
| --- | --- | --- |
| CP1 信息架构 | Tools 只有番茄时钟；原四项仍按归位设计从 Settings 可达；无重复入口 | Launcher → Tools → 番茄时钟路径与返回层级正确 |
| CP2 计时状态 | 单调时间差、暂停／恢复、跨 App、到零只完成一次、重置确认、重启初态；无每秒 NVS 写入 | 用可控时钟的聚焦检查完成边界验证；真实 25 分钟与 5 分钟各跑一轮，核对耗时 |
| CP3 视觉与生命周期 | 圆环与数字在 160 × 128 边界内；中英回退文案可显示；离开后无悬空 timer 或隐藏的 Wi-Fi 图标 | 目标板目视黑白对比、数字不跳位、圆环更新与无明显闪烁；10 轮打开／关闭后正常显示其他 App |
| CP4 待机协同 | 待机覆盖层不改变计时状态；唤醒键被吞掉 | 运行中进入黑底待机，唤醒后剩余时间按真实时长减少，未误触发暂停或返回 |

项目 `AGENTS.md` 规定固件构建、烧录和目标板验证由人工执行，可用 `idf.py build` 或 `idf.py -p COM5 flash monitor`。Agent 只做源码、配置、diff 静态检查并复核人工证据。没有实机照片／视频和人工结果前，视觉质量、刷新表现和计时准确性均标为未验证。

## 需审阅的产品取舍

- 第一版定为固定 `25 分钟专注／5 分钟休息`，由用户手动开启每段；这样主界面无需塞入时长编辑控件，圆环与剩余时间能成为视觉中心。
- 离开 Tools 后继续计时，但完成时不打断其他页面或待机画面，也不播放声音；如需后台完成提醒，可在有明确提醒方式后另立设计。
- 设计稿采用黑、白、灰三档视觉；是否需要保留顶层彩色 Wi-Fi 图标，建议以“计时详情页暂时隐藏、离开恢复”为准。
