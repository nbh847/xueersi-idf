# Tools 番茄时钟开发设计

状态：**已实施并通过负责人实机验收（2026-10-01 13:30，口头确认）**。施工与验收记录见 [Tools 番茄时钟施工文档](../goals/20261001-1036-tools-pomodoro.md)；实施期间 CP0 收口（`↑` 进番茄设置、手动硬件测试优先）、时长编辑与自动休息流程按用户要求追加，详见施工文档与文末演进记录。

当前施工依据：[Tools 番茄时钟施工文档](../goals/20261001-1036-tools-pomodoro.md)。最终视觉为直径 86 px 正圆、中央圆润玻璃沙漏、左右 16 px 数字，无「分钟」「秒」单位；保留精简动效、到点 3 声与独立声音开关。设置入口按键和蜂鸣器竞争语义在施工文档 CP0 收口。文末调整记录仅说明方案演进，以施工文档的最终交付记录与实际固件为准，HTML 保留为早期视觉参考。

## 实施顺序与依赖

本设计是已确认实施顺序的第 2 步，在 Launcher 与 Tools／Settings 信息归位独立验收后实施，空闲待机画面随后实施；当前进度以 `ROADMAP.md` 为准。计时根据实际经过时间计算，不依赖页面刷新次数，也不依赖待机功能先实现。本步独立验收开始、暂停、继续、完成及离开 App 后计时准确；待机期间继续计时的集成验收留到第 3 步。顺序确认不代表本设计细节已全部审定。

## 产品目标与边界

在 `Tools` 中提供第一个真正可用的工具：番茄时钟。默认 **25 分钟专注 + 5 分钟短休息**，专注／休息可在番茄设置中改为 1～180／1～60 分钟。用户手动开始专注，专注到点自动进入休息；休息完成后等待用户开始新一轮。计时不中断其他 App 的使用：离开 Tools、进入黑底待机画面后仍按真实经过时间前进，返回时显示准确状态。

第一版不做长休息、轮次统计、任务清单、震动、联网同步或跨重启计时恢复。2026-10-01 用户确认增加到点蜂鸣提示及番茄设置内的独立声音开关；完成时仍不弹全局提示。后台完成检测与声音输出需要独立于页面生命周期，不能仅在重新打开页面时检测。

## 与已写设计的关系

[Launcher 与 Tools／Settings 信息归位设计](launcher-tools-settings-reorganization-design.md) 仍负责把 Tools 现有 Wi-Fi、System Info、About、Assets 迁入 Settings，并把 Games 放到 Launcher 第三格。该设计此前把 Tools 写成“暂无工具”空状态；**本设计更新其目标状态为仅有「番茄时钟」一个入口**。若两个方案分步实施，信息归位后至番茄时钟落地前可以短暂显示空状态；最终验收以本设计的单入口 Tools 为准。历史上的四项诊断信息不回流 Tools。

[空闲待机画面设计](screen-idle-design.md) 到时会覆盖当前 App 画面，但不暂停番茄计时。任意键唤醒只恢复原页面且吞掉唤醒键；返回番茄界面时按当前时间更新圆环和数字。

## 视觉方案

我建议采用你提出的**黑白圆环倒计时**，这比在 160 × 128 小屏上铺满卡片或数字更清楚。区别是：圆环本身也表示剩余比例，数字负责精确时间，二者互相补足；页面不放番茄插画、渐变或大面积装饰。

| 区域 | 位置与样式 | 用途 |
| --- | --- | --- |
| 底色 | 全屏纯黑 `#000000` | 让圆环、时间与状态形成主次；背光直连 VCC，黑底不代表物理关屏 |
| 顶部 | `y=2～17`，12 px 小字，白色／浅灰 | 显示 `专注` 或 `休息`；暂停或完成时用文字明确状态 |
| 圆环 | 中心约 `(80,64)`、直径约 `86 px`、线宽约 `5 px`；暗灰底环 `#383838`，剩余弧为近白 `#F2F2F2` | 初始完整一圈，从 12 点方向顺时针缩短；到 0 时仅留底环，不用颜色作为唯一状态信号 |
| 时间 | 圆环内部沙漏居中，左右分别显示分钟与秒数（分钟超过 99 时显示三位），16 px 数字；无冒号和单位，固定位置 | 运行与暂停均显示剩余时间；秒数变化只重绘时间和圆环 |
| 底部 | `y=107～125`，12 px 小字或两个紧凑操作项 | 按状态显示最少的可执行操作；B 返回始终可用 |

目标屏幕草图，比例与字距以实机为准：

```text
┌──────────────────────┐
│        专注          │
│     ◜────────◝       │
│    │          │      │
│    │18 沙漏 24│      │
│    │          │      │
│     ◟────────◞       │
│   A 暂停     B 返回  │
└──────────────────────┘
```

运行时屏幕保持纯黑和灰白层次。全局 Wi-Fi 图标目前位于 LVGL top layer 且使用彩色；若要严格保持黑白，番茄详情页打开期间应由 Framework 提供受控的可见性接口暂时隐藏它，离开详情页或关闭 Tools 时恢复。不能由 Tools 直接销毁图标或更改 Wi-Fi Service。Tools 菜单仍沿用项目现有配色，进入计时详情页才切换为黑白，以让番茄画面完整、安静。

数字目标为 16 px，实施前核对现有字体令牌和实际字形；原 24 px 数字方案已废弃。中央沙漏与旋转帧规范见施工文档。

## 页面与按键

`Tools` 菜单仅有一项 `番茄时钟`。A 进入，B 返回 Launcher。番茄详情页根据状态显示：

| 状态 | 画面 | 按键 |
| --- | --- | --- |
| 未开始 | 完整白环，左右显示配置的专注时长（默认 `25`／`00`），标题 `专注` | A 按配置开始专注；B 回 Tools 菜单 |
| 运行中 | 白弧随剩余时间缩短，左右两组分钟／秒数；秒级更新 | A 暂停；B 回 Tools 菜单，计时继续 |
| 已暂停 | 停住的圆环和剩余时间，标题 `已暂停`，底部有 `继续／重置` 两项 | 左／右选项，A 执行；B 回 Tools 菜单且保持暂停。选择“重置”后立即回到未开始，使用当前配置的专注时长 |
| 专注到点 | 提醒一次并自动切换到休息计时页，不停留完成选择页 | 休息运行期间 A 暂停；B 返回，计时继续 |
| 休息运行／暂停 | 同一圆环布局，标题为 `休息`／`已暂停`，初始显示配置的休息时长（默认 `05`／`00`） | 与专注运行／暂停相同 |
| 休息完成 | 标题 `休息结束`，数字为 `00`／`00`，底部显示 `再来一轮` | A 按配置开始新一段专注；B 回 Tools 菜单 |

暂停与完成状态的两个操作项需在 160 × 128 实机上保持清楚的焦点样式，不能缩小到难读；必要时让底部两项分两行或改为独立轻量选择页，圆环仍是主画面。方向键仅在有选项的状态改变焦点，不在运行中切换阶段。A／B 的重复按键按现有释放锁存规则处理，一次实体按下只执行一次动作。不会因为误按方向键跳过工作或重置计时。

## 计时语义与实现落点

- 计时状态独立于 Tools 的 LVGL 页面对象，使用设备启动后的 64 位单调时间 `esp_timer_get_time()` 计算截止时间；不靠每秒回调递减整数，避免 App 关闭或屏幕待机期间漏秒。运行态读取快照时以 `max(0, deadline - now)` 得出剩余时间；显示秒数采用向上取整，使开始时确实显示 `25:00`，不会立刻跳 `24:59`。到达 0 后只转换一次完成状态，不出现负值。
- 暂停时保存剩余时长；恢复时从当前单调时间设新截止点。B 离开详情页只销毁 UI 对象和 UI 刷新 timer，不销毁计时状态。重新进入时读取最新快照并重建圆环。设备重启后计时回到未开始；计时状态不写 NVS。到点声音偏好需要持久化，仅在用户修改时写入，禁止每秒写 Flash。
- Tools App 只处理菜单和详情呈现；计时状态可放在独立的小型 `main/services/` 模块，或先放在不会随 App `close` 清空的私有状态中。选型以实现时最小可测范围为准；若需要后台完成状态查询，优先独立模块。无论落点如何，都不新增 FreeRTOS 任务或依赖网络时间。
- LVGL 页面约每秒更新数字与弧线；保留现有单块 DMA 缓冲，不使用全屏逐帧动画或新的位图资源。圆环优先核对项目已锁定的 LVGL 9.5 `arc`／绘图能力，避免自己维护一套像素缓冲。所有 LVGL 调用留在 UI 任务中。
- 进入页面时创建、离开时释放对象和刷新 timer。Wi-Fi 图标隐藏／恢复与页面生命周期成对，即使中途 A／B 切换或构建对象失败也不能留下全局图标被隐藏的状态。

## 验收检查点

| 检查点 | 静态检查 | 人工验证 |
| --- | --- | --- |
| CP1 信息架构 | Tools 只有番茄时钟；原四项仍按归位设计从 Settings 可达；无重复入口 | Launcher → Tools → 番茄时钟路径与返回层级正确 |
| CP2 计时状态 | 单调时间差、暂停／恢复、跨 App、到零只完成一次、重置确认、重启初态；无每秒 NVS 写入 | 用可控时钟的聚焦检查完成边界验证；真实 25 分钟与 5 分钟各跑一轮，核对耗时 |
| CP3 视觉与生命周期 | 圆环与数字在 160 × 128 边界内；中英回退文案可显示；离开后无悬空 timer 或隐藏的 Wi-Fi 图标 | 目标板目视黑白对比、数字不跳位、圆环更新与无明显闪烁；10 轮打开／关闭后正常显示其他 App |
| CP4 待机协同 | 待机覆盖层不改变计时状态；唤醒键被吞掉 | 运行中进入黑底待机，唤醒后剩余时间按真实时长减少，未误触发暂停或返回 |

项目 `AGENTS.md` 规定固件构建、烧录和目标板验证由人工执行，可用 `idf.py build` 或 `idf.py -p COM5 flash monitor`。Agent 只做源码、配置、diff 静态检查并复核人工证据。没有实机照片／视频和人工结果前，视觉质量、刷新表现和计时准确性均标为未验证。

## 产品取舍

- 第一版定为固定 `25 分钟专注／5 分钟休息`，由用户手动开启每段；这样主界面无需塞入时长编辑控件，圆环与剩余时间能成为视觉中心。
- 离开 Tools 后继续计时，完成时不弹窗；到点声音开启且系统声音开启时短响 3 声，其他页面和待机期间同样生效。
- 设计稿采用黑、白、灰三档视觉；是否需要保留顶层彩色 Wi-Fi 图标，建议以“计时详情页暂时隐藏、离开恢复”为准。

### 2026-10-01 实施期追加：时长编辑与圆润玻璃落位

- 用户实施当日追加要求：番茄设置页提供专注／休息时长编辑（`←→` 调整，1～180／1～60 分钟，默认 25／5，schema v3 持久化，离开行或返回时保存、写失败回退并提示）。本文「第一版不做时长自定义」的边界由该追加要求取代，统计、长休息、跨重启恢复等仍不做。

### 2026-10-01 新增确认：沙漏与到点声音

- 保留五款布局供选择，计时详情增加小沙漏，运行时每 4 秒间歇翻转半圈，暂停和完成时停止。2026-10-01 09:59 按用户要求改为侧边大沙漏，轮廓约 22 × 40 px，旋转预留约 46 × 46 px；左沙漏／右时间与左时间／右沙漏两种布局可对比，计时区圆环直径约 68 px，数字保持 24 px。最终左右位置尚待用户选择和目标板验收；仅更新局部，不做全屏逐帧动画。
- 专注与休息完成各短响 3 声，每声约 150 毫秒、间隔约 150 毫秒；每段只触发一次，重新打开页面不重复。默认采用现有蜂鸣器使用的 988 Hz 作为初值，响度与效果待实机验收。
- 增加「番茄时钟 → 设置 → 到点声音」，默认开启，持久化保存。系统 `sound_enabled` 为总开关，两项同时开启才发声；系统关闭时设置页说明「系统声音已关闭」。详情页 `↑` 进入番茄设置，B 返回详情，不暂停计时。
- 声音输出通过 Service 统一控制，App 不直接操作 LEDC；后台完成检测不依赖页面刷新。需处理与 Hardware Test 蜂鸣器的资源竞争，手动 Hardware Test 优先，提醒遇占用不排队、不补响，不扩大为完整音量或音效系统。
- 独立离线预览：`docs/pomodoro-styles-browser.html`，支持五款样式、暂停／恢复、模拟到点和声音开关试听。浏览器音色不代表实机；未实施固件，未构建或实机验证。
- 新增验收：专注／休息、跨 App／待机到点各提醒一次；两级开关静音、开关重启恢复、无重复响声；沙漏暂停／关闭释放；蜂鸣器与 Hardware Test 并用行为。

### 2026-10-01 10:03 侧边沙漏动效调整

用户确定沙漏放右侧，倒计时放左侧；不再保留位置选择。预览增加上部沙量递减、下部沙堆增加、落沙粒子与落点散沙，约每 6 秒翻转半圈后循环，暂停时冻结全部效果、完成时停止并显示下部沙堆。循环只是运行状态装饰，不代表完整 25 分钟的沙量比例，剩余时间以数字与进度为准。预览以约 12 fps 局部更新作为实现预算参考，实际 LVGL 动效、内存和刷新成本未验证；不增加全屏缓冲或 FreeRTOS 任务。

### 2026-10-01 10:08 精简动效预览

依据用户流畅度优先要求，HTML 替换为单条短落沙线、6 档预计算沙堆与 10 档翻转角度；去掉落点散沙。落沙约 10 fps，沙堆约每 1.1 秒变化，最后约 0.5 秒翻转按 20 fps 展示。缓存图形与节点，只提交变化部分；暂停、完成及后台隐藏时停止持续图形更新。此版本替代上一节的粒子／散沙与统一 12 fps 方案；固件可采用预生成翻转帧，具体帧率必须实机验证，不根据 HTML 声称性能达标。

### 2026-10-01 10:14 沙漏候选预览

上一版视觉效果未获用户接受，新增圆润玻璃、经典支架、像素沙漏、极简沙流、实心轮廓五种候选，统一左侧圆环／右侧沙漏，只改变沙漏轮廓与固定帧翻转节奏，仍保留单线落沙及 6 档沙量。经典支架只翻转内胆，其余翻转整体。用户尚未选择，不视为最终方案；HTML 语法及结构静态检查通过，浏览器目视、声音试听及固件性能尚未验证。
